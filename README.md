## 👩‍💻 About me

I'm a **Software Engineer** (ESPRIT, 2025) based in Tunisia. I like building products **end to end**: from the data model and the API to the screen people actually touch.

Today I work at **Bassetti Group** on an enterprise knowledge-management and laboratory (LIMS) platform, across **C# / .NET** services, REST APIs, **Angular** front-ends and **Python** services. Before that I shipped mobile apps in **Flutter**, **.NET MAUI** and **Kotlin**, and web platforms in **PHP** and **WordPress**.

**What I do**
- 📱 **Mobile apps**: cross-platform with Flutter and .NET MAUI, native Android (Kotlin) and iOS (Swift).
- 🌐 **Full-stack web**: Angular and React front-ends; Node.js, .NET, FastAPI and Spring Boot back-ends.
- 🏢 **Enterprise software**: business modules in C# / .NET and Delphi, REST APIs, migrations and customer deliveries.
- 🤖 **AI-assisted features**: conversational assistants and document extraction with Python services.
